## Day 6 built - workflow triggers

- Added user-owned manual, webhook, and interval-schedule triggers.
- Added trigger activation, pausing, deletion, manual firing, secret rotation,
  event history, and next/last run tracking.
- Added atomic trigger firing that reuses the durable workflow queue and
  provides replay-safe idempotency.
- Added HMAC-SHA256 webhook signatures over the exact request body and
  timestamp, constant-time signature comparison, a five-minute clock window,
  delivery identifiers, replay deduplication, input limits, and rate limiting.
- Added one-time webhook signing-secret display and immediate secret rotation.
- Added a scheduler that atomically claims due triggers with row locking,
  advances their next run, and drains every due schedule.
- Added a Triggers interface for creation, operation, history, webhook setup,
  schedule visibility, and manual runs.

## Day 7 built - credential vault

- Added authenticated AES-256-GCM secret encryption with unique nonces,
  contextual additional authenticated data, and keyed fingerprints.
- Added backend-only credential and version tables. Browser and authenticated
  database roles receive no direct table access.
- Added provider types for generic secrets, OpenAI, Anthropic, Slack, and
  GitHub.
- Added redacted credential responses, one-way plaintext handling, versioned
  rotation, retired-version tracking, and an access audit log.
- Added safe provider tests restricted to fixed allowlisted provider endpoints;
  generic credentials receive a local encryption-integrity test.
- Added production key-version configuration and a generated Render encryption
  key without exposing it.
- Added a Credential Vault interface for encrypted creation, masked listing,
  protected rotation, testing, deletion, and audit-history review.

## Blockers and constraints

- Render's free instance sleeps after inactivity, so scheduled triggers cannot
  run while the service is asleep and may execute late after it wakes. Reliable
  always-on scheduling will require an always-on worker or an external scheduler.
- The scheduler and job worker currently share the free backend process.
- The frontend build still reports a non-blocking bundle-size warning.
- React Router still reports two high-severity advisories in its unused
  server-component action path. AgentForge uses client-side routing and does not
  use that path; a forced downgrade would be a breaking change.
- Supabase leaked-password checking remains unavailable on the free plan.
