## Day 8 built - connector SDK and core pack

- Added one validated connector contract shared by graph validation, workflow
  execution, the API catalog, and the workflow builder.
- Added seven production connector actions: HTTP request, Resend email, Slack
  message, Google Sheets row append, Google Drive text-file creation, Supabase
  row selection, and Supabase row insertion.
- Connected every authenticated connector to the encrypted credential vault
  with per-user ownership and credential-provider compatibility checks.
- Added recursive `{{input}}` parameter templates and structured connector
  outputs.
- Added outbound protections: HTTPS-only URLs, embedded-credential rejection,
  DNS resolution checks, private/reserved network blocking, manual redirects,
  fixed timeouts, body/response size limits, restricted request headers, fixed
  provider endpoints, and Supabase host restrictions.
- Added recursive secret redaction so a provider cannot persist an echoed vault
  secret in workflow output.
- Expanded the vault to support Google, Resend, and Supabase credentials,
  including Supabase project URL metadata.
- Added connector configuration controls to the visual workflow builder.

## Day 9 built - human-in-the-loop workflows

- Added approval nodes with review instructions and configurable timeouts.
- Added a user-owned approval queue with pending and decision-history filters.
- Added approve, reject, and edit-and-continue decisions with optional notes.
- Added resumable workflow checkpoints that preserve active branches, selected
  edges, intermediate values, the next node, and token usage.
- Added waiting states across jobs, workflow runs, and step runs.
- Added atomic approval resolution with row locking and backend-only function
  permissions.
- Added rejection and cancellation propagation across approval, job, run, and
  step state.
- Added automatic approval expiry to the existing scheduler.
- Made retries checkpoint-aware so completed connector side effects and earlier
  workflow steps are not replayed.
- Added immediate cancellation for jobs paused at an approval.

## Blockers and constraints

- Live email, Slack, Google, and database writes require the user's real
  provider credentials and destination resources. Their contracts and safe
  execution paths are implemented, but the production test intentionally used
  only a temporary HTTP credential to avoid sending messages or changing
  external data.
- Google credentials currently accept access tokens; automatic OAuth refresh
  and consent flows remain future connector-platform work.
- Render's free instance may sleep, so queued jobs, approval expiry, and
  schedules can be delayed until the service wakes.
- The frontend build has a non-blocking large-bundle warning.
- React Router reports two high-severity advisories in its server/RSC action
  mode. AgentForge is a client-only Vite SPA and does not expose that mode; the
  package is on the newest 7.x patch, and no safe non-breaking 7.x version
  resolves the audit range.
