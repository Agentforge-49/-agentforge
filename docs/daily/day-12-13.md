- Added duplicate-content protection using SHA-256 document hashes.

- Added a complete Knowledge dashboard for base creation, retention and memory

## Day 13 built - bounded multi-agent orchestration

- Added user-owned multi-agent systems with draft, active, and paused states.
- Added specialist and worker membership with per-agent routing keywords.
- Added three execution strategies: deterministic keyword router, bounded
  parallel workers, and model-driven supervisor routing.
- Added three aggregation strategies: attributed concatenation, deterministic
  majority vote, and supervisor synthesis.
- Added immutable task records for every delegation, including parent task,
  agent, routing reason, depth, input, output, tokens, estimated cost, latency,
  status, and safe error details.
- Added hard limits for delegations, parallelism, depth, execution time, and
  monthly quota.
- Added SHA-256 task signatures and a per-run visited set to prevent delegation
  loops.
- Added supervisor output parsing with strict JSON extraction, worker
  allowlisting, deduplication, and deterministic fallback routing.
- Added partial-success handling for parallel workers: the run can continue
  when at least one bounded worker succeeds.
- Connected multi-agent runs to the durable queue, cancellation, stale-job
  recovery, unified observability, run detail, filters, export, and replay.
- Added a complete Multi-Agent dashboard for team creation, agent selection,
  routing keywords, guardrail limits, activation, pausing, live execution,
  task progress, final output, and run history.

## Issues found and fixed

- The first integration run found that `memory_entries` lacked an explicit
  composite relationship to its owning knowledge base. This prevented
  PostgREST from resolving memory counts. The same-owner foreign key was added
  to the migration and production database, then the complete integration
  suite passed.
- Chunk-boundary testing found a one-character edge case when a sentence
  boundary landed exactly at the requested maximum. The chunker now clamps the
  boundary and has regression coverage.
- Vote aggregation testing found that a normalized duplicate could replace the
  original winning representation. Aggregation now preserves the first stable
  output and has regression coverage.

## Blockers and constraints

- Production verification intentionally did not execute a real agent or
  multi-agent team because that would spend model quota. The durable execution
  path is fully connected and its deterministic structure, validation,
  persistence, limits, and API lifecycle were verified without cost.
- Retrieval is PostgreSQL full-text plus lexical fallback, not semantic vector
  search. This keeps the feature free today; embeddings and hybrid retrieval
  can be added later when a budget is available.
- The frontend reports a non-blocking large-bundle warning.
- The dependency audit reports a high advisory in React Router's unstable
  server/RSC mode. AgentForge is a client-only BrowserRouter application and
  does not use that execution path. The patched release requires the planned
  React Router 8 migration, so it was not forced into this two-day feature
  release.
- Render's free instance can sleep and delay the first request or queued run
  while it wakes.
