## Day 4 built - durable execution

- Added database-backed execution jobs for agent and workflow runs.
- Added atomic queue claiming with `FOR UPDATE SKIP LOCKED`.
- Added a background worker that drains queued work and records results.
- Added exponential retry scheduling, attempt limits, timeouts, cancellation
  state, and stale-job recovery after a worker interruption.
- Added atomic, user-scoped idempotent enqueue functions for agent and workflow
  runs.
- Changed agent execution from a blocking request to a durable queued job.
- Added job listing, detail, and cancellation APIs.
- Updated the agent-run screen to submit, poll, show retry/queue state, cancel,
  and display the completed result.
- Kept the queue implementation portable so the worker can move to an
  independent service when the project outgrows the current free deployment.

## Day 5 built - workflow graph v1

- Added workflows, workflow runs, and per-node step-run records with ownership,
  lifecycle state, version snapshots, timings, outputs, and errors.
- Added graph validation for node and edge limits, unique identifiers, missing
  references, unreachable nodes, cycles, input/output requirements, agent
  configuration, transforms, and complete condition branches.
- Added deterministic input, agent, transform, condition, and output nodes.
- Added ordered DAG execution with selected and skipped conditional branches.
- Made workflow agent nodes execute immutable published agent versions.
- Added workflow CRUD, activate, pause, run, run-history, and step-history APIs.
- Added a visual workflow editor foundation with a node canvas, agent picker,
  transform configuration, condition paths, draft saving, activation, queued
  execution, polling, and result display.
- Added Workflows navigation and application routes.

## Blockers and constraints

- Render's free instance sleeps after inactivity, so the first request after a
  quiet period may take roughly 50 seconds.
- The worker currently shares the free backend process. Jobs are durable, but
  independent horizontal worker scaling requires another service when budget
  becomes available.
- Supabase leaked-password checking requires a paid plan and remains disabled.
- The frontend build still reports a non-blocking bundle-size warning.
- The installed React Router release still reports two high-severity advisories
  in an unused server-component action path. AgentForge is a client-side app and
  does not use that path; the advisories remain tracked pending an upstream fix.
